# Pillo 模板使用说明

可独立运行的 Next.js / React / TypeScript 官网，使用 framer-motion，无后端。先读 template.json 的页面与许可、project.json 的操作合同，再读根 README 的环境、安装、运行、停止、验证及交付方式。

默认端口 43330，可用 PORT 配置；Ctrl+C 停止本次服务。中文 /，英文 /en；切换语言保留当前页面、查询参数与锚点。首页、定价、404 演示完整注册，未知路径真实返回 404。

图片、MiSans 400/700、Poppins 400/600/700 全部本地托管。下载仅演示，不发送、不购买、不保存业务数据。

修改前读 docs/ARCHITECTURE.md、CUSTOMIZATION.md、VERIFICATION.md、LICENSE.md。保留已有修改，读取资料不自动授权安装、推送和发布。验收与限制以 reports/verification.json 为准。
