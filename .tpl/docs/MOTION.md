# 动效清单与边界

参考页：首页、定价、404；已使用内置浏览器观察桌面、平板和手机布局，首页未发现视频元素。以下节奏为观察后实现的参数，未从参考站脚本提取精确数值，不声明逐帧一致。

| 区域 | 触发、方向和节奏 | 三端差异 |
| --- | --- | --- |
| 标题 | 输入/删除式循环；输入约 105ms/字、删除约 65ms/字，完整停留 2.3s；离屏停止计时、后台不推进 | 三端保留，减少动态时静态 |
| 首屏 | 标题上移入场约 0.9s，正文与按钮错峰 | 手机隐藏设备，按钮纵向铺满 |
| 功能手机 | 原生滚动连续驱动右侧向左移动、缩放、welcome/alarm/tracking/routine 交叉切换约 0.45s | PC/iPad 保留，手机按原站只显示三段紧凑文字 |
| 使用步骤 | 手持手机随滚动旋转/位移，三张玻璃卡按 0.13s 错峰进入 | 手机图片在前、步骤单列 |
| 数据 | 两条相反方向无限滚动，约 48s/55s 一轮；悬停、键盘聚焦、离屏和后台暂停 | 手机按原站显示三张静态图文卡 |
| 评价 | 纵向原生滚动推动四幕横向故事，文字与人物同步移动 | 手机改为普通纵向卡片，顺序移至价格和 FAQ 后，并使用原站手机人物素材 |
| 价格 | 月/年分段滑块弹簧切换；金额上下淡入出约 0.18s；年付展示 47.99/年及 3.99/月 | 手机单列，平板/桌面双列 |
| FAQ | 单项展开，高度与透明度过渡约 0.35s，加号旋转 | 三端键盘可操作 |
| 按钮 | 双行文字向上轮换约 0.35s，按下缩小 | 三端保留，不添加装饰箭头 |
| 菜单和切页 | 菜单顶部展开、链接错峰，Escape 关闭并恢复焦点；页面透明度约 0.35s | 手机菜单锁定背景；PC/iPad 使用水平导航 |
| 404 | 背景从 1.08 缩放至 1，约 1.4s；文案上移进入 | 三端保留 |

实际采样确认：标题从完整文本进入逐字状态；三段分别切换到 alarm/tracking/routine；评价轨道从无位移变为矩阵位移；数据轨道不同时刻位置变化，离屏后进入 paused。代码遵循 prefers-reduced-motion，但未实际切换系统减少动态设置，未逐项验收全部悬停/物理参数或全部设备的所有交互组合。

界面示意使用可翻译文字重新绘制，存在与原站英文截图的几何和排版差异；图片、主题、结构与主要滚动方式已对照。字体和中文标题依本模板约定调整，FAQ 的演示说明避免声称网站接入真实订阅或采集健康数据。
